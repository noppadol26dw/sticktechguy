Privacy Policy: Stick Tech Guy Uploader

Last updated: October 2, 2026

"Stick Tech Guy Uploader" is a private tool used only by the owner of the YouTube channel @sticktechguy. It uploads that channel's own videos and schedules when they are published. It is not offered to the public.

What data the tool uses

  • Google account access: after the channel owner signs in with Google, the tool receives an OAuth token for the YouTube Data API. It uses this token only to upload videos, set their title, description, tags and publish time, change the publish time of videos it uploaded, and read the signed-in channel's name to confirm it is the right channel.
  • Video files and text: the videos and their descriptions are made by the channel owner and sent only to YouTube.

Where data is stored

The OAuth token is stored only on the channel owner's own computer. The tool has no server and no database, and it does not collect analytics.

Sharing

The tool does not sell, share or transfer any Google user data to anyone. Data goes only between the owner's computer and YouTube.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at Google Account → Third-party connections. Deleting the token file on the owner's computer also ends access.

Contact

Questions: through the @sticktechguy channel page.
